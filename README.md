# 🧠 FlipMatch - Memory Puzzle Game

**FlipMatch** is a modern, beautifully crafted Android memory matching puzzle game built entirely with **Jetpack Compose** and **Material 3**. Test your memory, challenge your concentration, and beat your personal bests across multiple difficulty levels and card themes!

---

## ✨ Features

- **Jetpack Compose & Material 3:** Modern declarative UI with dynamic theming and smooth animations.
- **Multiple Difficulties:** Choose from various grid sizes and challenge levels (Easy, Medium, Hard).
- **Diverse Themes:** Enjoy different card themes and emoji sets.
- **Brain Training:** Designed to boost memory, focus, and cognitive agility.
- **High Scores & Timer:** Track your best completion times and fewest moves.
- **Dark Mode Support:** Seamless toggle between light and dark themes.
- **Haptic Feedback:** Tactile vibrations on card flips and interactions.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose & Material 3
- **Architecture:** MVVM (Model-View-ViewModel) with Kotlin Coroutines & StateFlow
- **Minimum SDK:** API 24+
- **Target SDK:** API 37

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/FlipMatch.git
   ```
2. Open the project in **Android Studio** (Koala / Jellyfish or newer).
3. Sync Gradle and run the `:app` module on an emulator or physical device.

---

## 📖 How to Play

1. Tap any two cards to flip them over and reveal the emojis.
2. If the emojis match, they stay face up!
3. If they don't match, they flip back over.
4. Match all pairs within the target move limit before running out of moves to win.
5. Try to beat your best moves and completion time!
